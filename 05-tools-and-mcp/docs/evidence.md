## Run 1 · toolkit standards (2026-09-21): Tools and MCP

Full report: [`technical-hackathon-toolkit-2026-09-21/research.md`](../../_research/technical-hackathon-toolkit-2026-09-21/research.md)

- **Claude Code mechanics:**
  - `claude mcp add` supports `--transport http` and the `--` form for stdio servers.
  - Scopes are local (default), project (`.mcp.json`, committed) and user. `.mcp.json` expands `${VAR}`.
  - Output warns at 10k tokens and is capped at 25k.
  - Official warning: trust servers first, because anything that fetches external content can inject prompts [T43].
- **Stitch:**
  - The official flow is Stitch → pull design context → `DESIGN.md` → React/Tailwind [T44].
  - The remote endpoint `stitch.googleapis.com/mcp` with an `X-Goog-Api-Key` header is confirmed, but Claude Code issue #41664 (2026-03, closed as not planned) reports the header ignored and OAuth DCR failing [T45].
  - The community proxy `@_davideast/stitch-mcp` is explicitly not Google-affiliated [T46].
  - The sync is **one-way**. No source shows code→Stitch CSS sync.
- **21st:**
  - "Magic MCP is now the 21st MCP." Tools are `generate`, `get_inspiration` and `search_logo`, and old keys were reset [T47].
  - The README (plugin marketplace) and the website (`npx @21st-dev/cli@latest init --client claude`) give different install routes [T19][T47].
  - `generate` requires AI access on the account. No prices are published.
- **Others (primary READMEs and docs):**
  - Supabase MCP: `read_only=true`, `project_ref`, feature groups; never production [T48].
  - Playwright MCP: Microsoft itself suggests its CLI plus skills is more token-efficient, and says the MCP server is not a security boundary [T49].
  - Context7: community docs, accuracy not guaranteed [T50].
  - Vercel MCP: official beta with full account power, including deploying and purchases [T51].
  - Stripe: sandbox, restricted keys, human confirmation [T52].
  - shadcn: `mcp init --client claude` [T53].
  - GitHub: `--read-only` and toolsets [T56].

## Run 1 · toolkit standards (2026-09-21): MCP ecosystem and AI dev tools

Full report: [`technical-hackathon-toolkit-2026-09-21/research.md`](../../_research/technical-hackathon-toolkit-2026-09-21/research.md)

*Deepen #2, 2026-09-22 (cost tags: 🆓 free · 🆓* free tier · 💳 trial · 💰 paid).*

- **Spec:** the current MCP spec is **2026-07-28**. It has a stateless core (no handshake or session header), multi round-trip requests, and CIMD + RFC 9207 auth. **SSE, Sampling, Roots and Logging are deprecated** [T103].
- **Registry:** the Official MCP Registry has been in preview since 2025-09-08 [T104]. A third party counted about 9.6K servers in May 2026 (low confidence).
- **Claude Code:**
  - MCP tool search is **on by default**, and output is capped at 25K tokens [T43].
  - `claude-plugins-official` bundles MCP servers for github, supabase, vercel, sentry, linear, notion, figma, slack and others [T105].
  - Community plugins are screened and pinned to a commit SHA, but Anthropic doesn't control the MCP servers they bundle [T105].
- **Reference servers:** `modelcontextprotocol/servers` keeps only 7 (Everything, Fetch, Filesystem, Git, Memory, Sequential Thinking, Time). Postgres, SQLite, GitHub, Brave, Redis, Sentry, Slack and Puppeteer are **archived** [T106].
- **Vendor servers:**
  - Chrome DevTools MCP (🆓; sends usage stats unless you opt out) [T107].
  - DBHub for any Postgres (🆓) [T43].
  - Neon, MongoDB, Redis, Netlify, Firecrawl, Exa, Ref, awslabs (all active) [T122].
  - The Browserbase MCP repo is **archived** [T122].
  - Figma MCP needs a **paid Dev/Full seat** (💰) [T108].
- **Claude Code cost:** it is **not** on the Free plan. It needs Pro ($20/month) or more, or an API key (💳/💰) [T109].
- **Hooks:** official hooks can auto-format after edits and block edits to protected files (exit code 2) [T110].
- **Free dev tools:**
  - Copilot Free gives 2,000 completions/month [T111].
  - Lovable Free gives 5 build credits/day (up to 30/month) [T112].
  - Figma Starter gives 150 AI credits/day [T113].
  - The Gemini API no longer publishes fixed free limits; check them in AI Studio [T114].
  - Antigravity ($0), Kiro (50 credits), v0 ($5/month), Bolt (300K tokens/day), Groq, Cerebras and OpenRouter free tiers come from search summaries only (medium confidence).
- **Gone:** **GitHub Models was retired on 2026-07-30** [T115]. **Firebase Studio** closed to new users on 2026-06-22 and shuts down on 2027-03-22 [T116]. Both were verified by the lead.
- **Security:**
  - Tool poisoning and rug pulls [T117].
  - GitHub MCP "toxic agent flow" (May 2025) [T117].
  - **postmark-mcp npm backdoor** (Sep 2025, BCC'd all mail from v1.0.16) [T118].
  - Spec rules: no token passthrough, sandbox local servers, minimal scopes [T119].
  - Claude Code: `/sandbox`, and trust prompts that are skipped under `claude -p` [T120].
  - `mcp-scan` is now **Snyk Agent Scan**: `uvx snyk-agent-scan@latest`, needs `SNYK_TOKEN`, and sends tool descriptions to Snyk [T121].

## Run 2 · GitHub repos (2026-09-22): Force-multipliers

Full report: [`technical-hackathon-github-repos-2026-09-21/research.md`](../../_research/technical-hackathon-github-repos-2026-09-21/research.md)

- **AI coding agents:** OpenCode (209k, moved to `anomalyco`), Claude Code 147k, Codex 125k, OpenHands 88k, Cline 68k, Goose (now `aaif-goose`) [G1][G32]. **The Gemini CLI free service ended 2026-06-18** [G13][G14]. **Roo Code is archived** [G1]. The claim that Continue is archived is **overturned**: the API shows it active [G1]. Aider was last pushed 2026-05-22 [G1].
- **Lists:** public-apis 482k, free-for-dev 137k, awesome-selfhosted 320k, awesome-public-datasets 79k [G1]. Two famous lists (the-book-of-secret-knowledge, the-art-of-command-line) are stale [G1].
- **Automation and testing:** browser-use 115k, Playwright 96k, Puppeteer 95k, Stagehand 24k; faker-js and MSW are active [G1]. json-server's last push was 2026-03-23 [G1].
- **Pitch tools:** Excalidraw 132k, Mermaid 90k, reveal.js 72k, Slidev 48k, VHS 20k [G1]. Slidev is recommended for developer experience and Marp for simplicity [G33].
